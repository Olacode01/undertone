# Screenshots

Drop the README images here. Referenced from the main README, so the filenames
matter:

| File | What it should show |
|---|---|
| `before.png` | The original photo — royal blue, which the matcher scores `poor` |
| `after.png` | The try-on result in a palette colour |
| `profile.png` | The colouring card, including the background-contamination warning |
| `ranking.png` | The ranked garment table with ΔE reasoning visible |

`profile.png` is the one worth getting right. A system that flags its own
unreliable input and explains what it did instead reads as far more trustworthy
than a clean result with no caveats.

To capture on macOS: **Cmd+Shift+4**, then drag. Or **Cmd+Shift+4** then Space
to grab a whole window.
